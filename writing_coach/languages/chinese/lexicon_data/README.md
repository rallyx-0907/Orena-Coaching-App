# Chinese lexicon data

Dictionary facts for Chinese words: simplified and traditional forms, pinyin,
English senses, and per-character Mandarin readings, Hán-Việt readings and
definitions. This is P1 of `docs/ORENA_AI_COST_REDUCTION_PLAN.md`: a word sense
or a pinyin reading is a dataset fact, so it is looked up here and never asked
of a language model. Nothing in this directory is generated by AI.

## Modification notice

Changed on 2026-10-04 by the Orena project. The CC-CEDICT text file was
**repacked into a different container format**: entries are grouped by the first
character of their simplified headword and each group is stored as one zlib
record. Headwords, traditional forms, pinyin and English senses are copied
through unchanged; no entry was added, edited or reordered within its group.
Entries whose simplified headword does not begin with a CJK Unified Ideograph
(U+3400–U+4DBF, U+4E00–U+9FFF) are not included. From Unihan, only the three
fields above are kept, and only for characters that occur in a kept headword.

Share-alike: this repacked data remains under CC BY-SA 4.0. The learner-facing
dictionary credits CC-CEDICT wherever a sense from it is shown.

The conversion is reproducible:

```
python scripts/build_chinese_lexicon_pack.py --cedict <saved export> --unihan <Unihan.zip>
python scripts/build_chinese_lexicon_pack.py --check     # verify the committed pack
```

## Format

`zh_lexicon.index.json` holds `format` (`orena.zh-lexicon.v1`), the source
provenance, counts, `pack_sha256` and `offsets`: leading character →
`[offset, length]` into `zh_lexicon.pack`. Each record decompresses to
`{"w": {simplified: [[traditional, pinyin, [sense, ...]], ...]}, "c": {"m", "v", "d"}}`,
where `c` is that character's Unihan readings when it has any.
