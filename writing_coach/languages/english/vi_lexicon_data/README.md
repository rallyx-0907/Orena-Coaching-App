# English-Vietnamese dictionary pack

Vietnamese meanings for English headwords, each with the English sense it translates. The word
tap reads a word's base meaning in Vietnamese from here at no cost (D-246), before any
translation layer: a word sense is a dataset fact, so it is looked up, never asked of a
language model. Nothing in this directory is generated by AI. The pack is data, kept apart from
Orena's code; the loader is `writing_coach/languages/english/vi_lexicon.py`.

## Provenance

| | English Wiktionary, Vietnamese translations |
| --- | --- |
| Upstream | [English Wiktionary](https://en.wiktionary.org) translation tables (`lang_code` `vi`) of its English entries, as extracted by [Wiktextract](https://github.com/tatuylonen/wiktextract) and published by [kaikki.org](https://kaikki.org/dictionary/English/) (`kaikki.org-dictionary-English.jsonl.gz`) |
| Release | kaikki.org extraction of 2026-10-03 from the enwiktionary dump of 2026-09-02; SHA-256 of the input recorded in `en_vi_lexicon.index.json` under `sources` |
| Fields kept | headword, part of speech, the translation table's English sense label, the Vietnamese translations |
| Size | 16,660 headwords, 20,239 senses, 29,271 Vietnamese translations; pack 0.65 MB |
| Licence | Creative Commons Attribution-ShareAlike 4.0 — [`CC-BY-SA-4.0.txt`](CC-BY-SA-4.0.txt). Wiktionary text is also available under the GFDL; that side is not used. |
| Attribution | Wiktionary contributors; extraction by Tatu Ylonen's Wiktextract (kaikki.org) |

Not used, by decision (D-246): Vietnamese Wiktionary and the Hồ Ngọc Đức / Free Vietnamese
Dictionary Project data. A word this pack does not carry falls through to the next layer of
the word tap.

## Modification notice

Changed on 2026-10-20 by the Orena project. From each English entry, only its Vietnamese
translations are kept, grouped by the English sense label of their translation table; entries
of one headword are merged. A translation cell that lists alternatives with an English "or"
is split into one translation per alternative (the committed pack predates the split in the
build script; the loader applies the same split when it reads it). The Vietnamese text is trimmed, normalised to Unicode NFC
(diacritics kept), de-duplicated, and dropped when empty, longer than 60 characters, or not
written in Vietnamese orthography (a Han or Nôm form, or another language's word). Within an
entry, senses are ordered by how many languages the translation table translates them (ties
keep Wiktionary's order), and translations tagged archaic, obsolete, dated, historical or rare
come after the others. The result was **repacked into a different container format**: headwords
are grouped by their first two characters and each group is stored as one zlib record. Text is
otherwise unchanged.

Share-alike: this pack, and any adaptation of it, remains under CC BY-SA 4.0 and is published
with its licence text. The share-alike reaches this data only; Orena's code and its other data
files are separate works, as with the vendored CC-CEDICT. The learner-facing Licences and data
sources page credits it (`writing_coach/licences.py`, `wiktionary-en-vi`).

The conversion is reproducible and is also the update script (download the current
`kaikki.org-dictionary-English.jsonl.gz` outside the repository, then):

```
python -I scripts/build_en_vi_pack.py --kaikki <kaikki.org-dictionary-English.jsonl.gz> --release <extraction date>
python -I scripts/build_en_vi_pack.py --check     # verify the committed pack
```

## Format

`en_vi_lexicon.index.json` holds `format` (`orena.en-vi-lexicon.v1`), the source provenance,
counts, `pack_sha256` and `offsets`: the first two characters of the casefolded headword →
`[offset, length]` into `en_vi_lexicon.pack`. Each record decompresses to
`{headword: [[part_of_speech, english_sense_label, [vietnamese, ...]], ...]}`, the part of speech
being Wiktextract's (`noun`, `verb`, `adj`, `adv`, `name`, ...).
