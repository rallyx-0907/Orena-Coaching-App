# Orena Brand & Mascot Reference Library

## Authority

`references/00_MASTER_REFERENCE_APPROVED.png` is the **human-approved master visual reference**.

Agents MUST treat that image as the primary visual authority for:
- mascot proportions;
- face;
- ear shape;
- tail shape and stripes;
- flat-vector construction;
- palette;
- warmth;
- friendliness;
- wordmark direction;
- overall balance between cute and mature.

The other reference sheets and individual crops extend the approved system.
They do not supersede the master reference.

## Brand model

Orena is a friendly exploratory learning companion.

The brand should feel:
- curious;
- warm;
- supportive;
- exploratory;
- modern;
- meaningful;
- suitable for both young and adult learners.

It should NOT feel:
- childish preschool;
- corporate SaaS;
- generic AI;
- gaming mascot-first;
- photorealistic;
- 3D-rendered.

## Three distinct layers

1. **Logo / mark**
   - minimal;
   - scalable;
   - suitable for favicon/app icon;
   - red-panda / curled-tail DNA;
   - does not need the full mascot.

2. **Mascot**
   - full red panda;
   - used for emotionally useful moments;
   - can carry different props/actions;
   - should not dominate content-learning surfaces.

3. **World illustration**
   - content and discovery environments;
   - may include the mascot;
   - may use light paper/print texture;
   - content remains the protagonist.

## Mascot invariants

When generating a new pose, preserve:
- the same red-panda identity;
- rounded face and cheeks;
- warm orange/red fur;
- cream facial mask;
- dark navy/brown limbs and details;
- large curled striped tail;
- compact, friendly body proportions;
- clean flat shapes;
- soft restrained shading;
- no realistic fur rendering;
- no drastic redesign of eyes, ears, muzzle, or tail.

The mascot must still be recognizable if the prop is removed.

## Props

Props communicate the moment. They are not permanent mascot anatomy.

Allowed examples:
- book;
- notebook;
- headphones;
- laptop;
- backpack;
- map;
- telescope;
- flashcard;
- microphone;
- speech bubble;
- pencil;
- media player;
- small plant;
- flag;
- globe.

Do not permanently attach a book or headphones to the mascot identity.

## Usage rule

Before generating anything new:
1. inspect `references/00_MASTER_REFERENCE_APPROVED.png`;
2. inspect the closest file in `actions/`;
3. inspect the closest emotional state in `expressions/`;
4. reuse an existing asset if it communicates the learner moment;
5. only generate a new pose if needed;
6. compare the result against the master reference before accepting it.

## In-app philosophy

The mascot supports the experience; it does not overpower it.

Good places:
- onboarding;
- empty states;
- transitions;
- encouragement;
- discovery moments;
- celebrations;
- journey/progress moments;
- lightweight hints.

Usually avoid a large mascot in:
- long Reading passages;
- active Listening video;
- dictation input;
- detailed Writing editor;
- dense feedback/review;
unless the mascot has a clear learner purpose.

## EN/ZH

Mascot art is language-neutral.
Text around the mascot must respect EN/ZH parity.
Do not create separate visual mascot identities for English and Chinese.
