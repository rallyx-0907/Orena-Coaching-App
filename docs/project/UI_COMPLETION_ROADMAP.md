## 1. The eight Coming-soon screens

All eight routes exist in `shell/routes.js` and are deliberately not registered in
`shell/screens.js` **[V]**. They are Coming soon because the frame's own logic is client regex
over sample content (D-068) and no backend serves them (`UI_BACKEND_GAPS.md` Wave B sections).

**E1, one engine for five screens [I].** One server endpoint, transient (stores nothing),
versioned, language-neutral: input `{text, language, support_language, task: {kind, prompt,
context, core_message?, target_word?}}`, output judgement enums (not free numbers), `one_fix`,
`alternative`. It serves Timed Reaction, Context Rewrite, Timed Writing, Mock Interview and
Context Transfer. It is a backend contract, not a schema change.

| Order | Screen | Reuses | New | Schema | Effort |
| --- | --- | --- | --- | --- | --- |
| 1 | 49 Sound / Tone | `word_audio_api` (reading-bound audio, Wikimedia then Kokoro); deterministic scoring | an authored minimal-pair (en) and tone-set (zh) bank (H3) | no | S-M, 1 session |
| 2 | 34 Timed Recall | vocabulary library cards + `POST /api/library/vocabulary/{word}/review` | threshold (H5); IME-aware timing for zh | only for "Fast retrieval evidence" (H7) | S, 1 session |
| 3 | 43 Timed Reaction | recorder, mic sheet, `POST /api/speech/transcribe`, `voice-invitations.js` | E1, built here first; more prompts (H3) | no | M, 1-2 sessions |
| 4 | 32 Retell | `GET /api/listening/library/{id}`, React's `phraseReused`, ASR, coaching | key-point extraction (H6) | no (A) | M, 1-2 sessions |
| 5 | 37 Context Rewrite | `/api/dictionary/registers` as a hint only | E1 `rewrite`; contexts per language (H3) | no | M, 1-2 sessions |
| 6 | 38 Timed Writing | E1, `writing_limits` counting | short prompts (H3) | no | S, 1 session |
| 7 | 48 Mock Interview | ASR, coaching, E1 | question sets per role, the summary (STAR) | no | M-L, 2 sessions |
| 8 | 35 Context Transfer | vocabulary library, E1 | contexts per word, "used right" judgement | only for "Transferred" (H7) | M, 1-2 sessions |

About 10-13 agent sessions. Each is one vertical slice: measured against its frame (rule 42),
rule 49 at the four sizes, en/vi/zh, light/dark, touch, with Chinese in the same batch (Sound /
Tone differs most: IPA pairs for English, four tones for Chinese). When a screen leaves Coming
soon, its surface name and purpose are published for the agent (AGENT_CONTRACT v5 section 6.2).

## 3. The cutover

**Entry conditions.** Human approval of Waves A and B; the Grammar screens rebuilt (step 1);
the preparation above done; H8 and H9 decided; a parity list in which every old flow has a
successor or is retired by the human (open: `url:` content, `#/language` / recall, `#/continue`,
per-skill libraries, Growth summary); AA in both themes and rule 49 at four sizes on the cutover
build; the 8011 sandbox migrated (BLOCKED today on the human's 0015/0016 run); old device-memory
keys still readable; explicit human instruction and a DECISION_LOG entry before
`LEGACY_TOMBSTONES.md` changes; the full gate green locally and CI evidence on the PR.

**What is deleted, each with a tombstone line.** `templates/orena/index.html` (the new template
serves `/`); `static/orena/app.js` (`main.js` is the only entry); `static/orena/ui/*.js`, 63
modules (after the moves above); the 18 root Dark Glass stylesheets (`kit/tokens.css` is the only
colour owner); `static/orena/theme.js` (`kit/boot.js`, D-097); the curled-tail `mark.svg` if
unused (D-090). `product/legacy-routes.js` is rewritten, not tombstoned. Kept:
`static/admin.js` (AGENTS section 7), `docs/design/canonical-ui/superseded/**`,
`docs/visual-references/**` (untouched).

**Redirects.** About 30 old addresses map to new routes (for example `#/encounter?id=media:X` to
`#/listen/X`, `&intent=dictation` to `#/listen/X/dictation`, `#/expression?id=essay:N` to
`#/write/N`, `#/preferences` to `#/settings`, `#/history` to `#/progress?tab=history`,
`#/continue` to `#/today`, `/next#/...` to `/#/...`). They run before the new router's `match()`,
because `#/practice` and `#/progress` exist in both UIs with different meanings. Old ids with
no new kind (`url:`, `voice:`, R5 grammar ids) need the parity decision. The full table is in
the planning notes and becomes the rewritten `test_orena_legacy_routes` gate.

**Gates.** About 20 domain-only gates stay. 7 are split, keeping the domain half. About 35
old-UI gates retire, each only after its guarantee is shown in a successor gate. Examples:
`foundation` AA becomes `test_orena_kit`; the lookup race and vocabulary paging need explicit
assertions ported before their gates go. Python validators that assert the old UI are rewritten,
not deleted (`validate_architecture.py`, `validate_project_memory.py`,
`tests/test_orena_routes.py` and two others). The ESM-graph gate must prove no module imports
`ui/`.

**Rollback.**
- Tag the pre-cutover commit and push the tag.
- Ship the cutover as one PR in three commits: (1) the moves, with no behaviour change; (2) `/`
  switched to the new UI, with the redirects and new gates; (3) the old UI deleted, the tombstones
  written and the old gates retired.
- Merge with a merge commit, so one `git revert -m 1` undoes it.
- No schema, migration or volume change, so rollback touches no data.
- The old UI is not kept behind a flag, unless the human approves a time-limited alias.
- No force-push. `main` stays the human's.

**Top risks.** Admin losing its host; the indirect `ui/` import; redirect collisions; a gate
retired without its guarantee; shipping R5 Grammar if the cutover comes before step 1.
