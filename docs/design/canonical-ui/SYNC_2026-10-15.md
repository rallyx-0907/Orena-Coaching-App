## What changed in the design (line diff against the previous pin: 45 diff lines, all in the Discover frame and the state script)

Only the Discover frame (`data-screen-label="Discover"`) and its handlers changed. No other frame, sheet or token changed;
the Import sheet frames (`imp` states: type, text, preview, processing, error) are byte-identical.

- **Discover header**: the "+ Import" button is removed. "Filters" stays.
- **New nested frame `data-screen-label="Create lesson"`**, between the header and the search bar (24px below the header,
  16px above the search): a card (radius 24, a surface-to-accent-wash gradient, the Orena Intelligence mark as a faint
  watermark) with
  - a head: the gold spark mark on a 48px tile, the title "Turn anything into a lesson" with an "Orena Intelligence" pill,
    and "Video, links, documents or audio. Orena handles the rest.";
  - a four-tab segmented control (`role=tablist`): Link / Video, Text, Document, Audio (two columns under a 560px
    container, via the new `@container` rule at line 72);
  - one field per kind: a link input (link icon), a three-row textarea, or a dashed "Drop a PDF, EPUB or DOCX, or choose
    one" / "Drop an audio file or choose one" button; beside it the gradient "Create lesson" button with the spark;
  - three hint chips per kind (YouTube / Website / MP4; Article / Email / Notes; PDF / EPUB / DOCX; MP3 / M4A / Podcast).
- **State script**: new `icTabs`, `icIsLink`, `icIsText`, `icIsFile`, `icDrop`, `icHints`, `icVal`, `icText`, `icKey`,
  `icCreate`, `icChoose` bindings and `icCreate()`: a link that looks like `http(s)://host.tld` goes to the Import sheet's
  preview step (`imp:"preview"`), anything else to its error step; text goes to the Import sheet's text step with the text
  filled in; document and audio only toast "File and audio import are not built in this round". Empty link or text toasts
  "Paste a link first" / "Paste some text first".
- **Vietnamese strings** for all of the above were added to the `VI` dictionary (one line, 2528 → 2548).
