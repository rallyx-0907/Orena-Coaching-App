## How the copy was made

`Orena.dc.html` is over DesignSync's 256 KiB cap, so the export is the source. Both files were copied byte for byte
and their SHA-256 checked against the export; `PINS.tsv` carries the new sizes and hashes. The previous bytes are in
Git history.
